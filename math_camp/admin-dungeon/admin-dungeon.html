Dungeon

Shard balances, what every camper is carrying, and who's allowed in.

🚧 Access

Closing the dungeon stops entry, the shop, the starter pick and the exchange. It does not touch anyone's maze history, so nobody gets to re-claim the maze reward on the way back in, and it does not take anyone's bag away — inventories stay readable below. Anyone mid-run is banked as if they'd walked out, so they keep what they'd earned.

🧹 Inventory repair

Clears out the copies left behind by the duplication bug: anything currently worn is removed from the loose bag, and non-stackable gear is clamped to one. Stacks of arrows are left alone. Safe to run more than once.

🎁 Chests

Every one-time reward in camp. Resetting one hands it back to that camper so they can open it again — it clears the "already opened" flag and nothing else, so nobody loses points or items they were already given. Filled circles are chests they've opened.

🎒 Campers

Shards are editable in place — type a number and pick Set or Add (a negative number takes shards away). Every change lands on the transaction log.
